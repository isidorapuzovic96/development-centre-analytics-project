# Power BI

`HR.pbix` je finalni Power BI fajl korišćen u projektu.

Model koristi:

- `FactAssessmentScore`
- `DimCandidate`
- `DimAssessmentGroup`
- `DimCompetency`
- `DimAssessmentMethod`

Glavne DAX mere su dokumentovane u `dax_measures.md`.

Dashboard je organizovan na tri stranice: Overview, Assessment Methods Analysis i Candidate Detail.
