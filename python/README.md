# Python

`hr_analysis.py` je jedan jednostavan end-to-end Python pipeline.

Redosled:

1. učitavanje source CSV-a
2. data-quality provere
3. identifikacija tri potvrđene greške za Integritet/Test
4. cleaning
5. weighted competency score
6. overall score
7. osnovna EDA
8. reconciliation

Objašnjenja u kodu su na srpskom, dok su tehnički nazivi kolona i promenljivih na engleskom.
