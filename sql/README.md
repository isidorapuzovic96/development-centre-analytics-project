# SQL

SQL deo projekta koristi SQL Server.

Jedan glavni fajl `development_center_hr_analytics.sql` sadrži:

- kreiranje baze
- dimension tabele
- fact tabelu
- foreign key veze
- business views
- JOIN / GROUP BY / WHERE / agregacije
- osnovne validacione upite

Model je organizovan tako da se ponavljajući opisni podaci nalaze u dimension tabelama, a assessment rezultati u fact tabeli.
